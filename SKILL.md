# Déjà Vu — portable agent instructions

Use this skill when entering an unfamiliar repository, starting a new task, finishing a coding session, or proposing a reusable lesson.

## Orient

1. Read the repository's authoritative instructions (e.g. `AGENTS.md`, `CLAUDE.md`) and task request.
2. Read `.dejavu/README.md` if present; select only task-relevant ontology, topology, epistemology, and accepted wisdom.
3. Follow source links and verify any time-sensitive claim against code, docs, or issues.
4. Distinguish facts, assumptions, and unresolved questions. Do not treat proposed lessons as accepted.

## Handoff

Record task scope, current branch/PR, changed files, tests run and results, unresolved issues, and concrete next actions. Do not include secrets or full transcripts.

## Learn

Propose a lesson only when it is supported by a concrete mistake, bug, review, test, or PR. Include evidence and a prevention step. Place it in proposals until reviewed.

## Reconcile

Flag outdated, conflicting, and superseded knowledge. Prefer updating a source of truth and referencing it over copying it into Déjà Vu. Do not silently overwrite accepted knowledge.

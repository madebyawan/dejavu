# Contributing

Déjà Vu is in early bootstrap. Please open an issue describing the problem, the proposed change, and how it will be tested before introducing major new abstractions. Keep the core dependency-light, local-first, and compatible with multiple coding agents. Include tests for CLI behavior and avoid collecting private project knowledge in public fixtures.

## Public-repository data boundary

This project and its issues, pull requests, comments, commit messages, tests, fixtures, documentation, logs and screenshots are public. **Never name, link to, describe identifying details of, or copy content from a nonpublic repository or private project into any of these public surfaces.** This includes repository owners, paths, issue/PR IDs, internal product names, source fragments and cross-references. Use entirely fictional examples or verified public projects. Private evaluations must remain local, and only reviewed, anonymized aggregate metrics may be published. Before posting, scan your proposed public artifact for identifying references and sensitive content.
